# **App Name**: Unrestricted AI Accessor

## Core Features:

- Unfiltered Prompt Input: Provide a text input field for users to enter their prompts without any filtering or restrictions.
- Unrestricted LLM Output: Utilize a large language model (LLM) to generate responses based on the user-provided prompts. The LLM should not have any built-in content filters or restrictions.
- Response Display: Display the LLM-generated response in a clear and easily readable format.
- Disclaimer: Include a disclaimer emphasizing that the application provides unrestricted access to AI and that users are responsible for the prompts they enter and the content generated.

## Style Guidelines:

- Primary color: Black (#000000) for a clean and professional look.
- Secondary color: White (#FFFFFF) for contrast and readability.
- Accent: Dark Gray (#333333) for subtle highlights and interactive elements.
- Use a professional, smooth, sans-serif font (e.g., Open Sans, Lato) for optimal readability and a modern feel.
- Maintain a clean and minimal layout with ample whitespace for a professional appearance. Use clear visual hierarchy to guide users.
